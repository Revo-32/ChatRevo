# Chat Revo 1.1.1

방송 중 시청자 수는 갱신되지만 채팅이 멈춘 채 남을 수 있는 연결 복구 문제를 수정했습니다.

- 치지직 채팅 서버 연결이 끊기면 공식 페이지가 먼저 재연결을 시도할 시간을 줍니다. 연결이 계속 열리지 않으면 같은 채널의 채팅 페이지를 다시 엽니다. 반복 실패 시 재시도 간격을 늘립니다.
- 채팅 연결이 열려 있으면 메시지가 없는 시간에는 새로고침하지 않습니다.
- 새 채팅이 몰릴 때 기존 메시지 목록의 배경색을 반복 검사하는 작업을 줄였습니다.
- 휠 입력이 취소되어 목록이 움직이지 않은 경우에도 최신 채팅을 계속 따라갑니다.
- WebView2 채팅 렌더러가 종료되면 페이지를 자동으로 다시 엽니다.

설치형은 **설정 → 업데이트 → 업데이트 확인 → 재시작하여 적용**에서 업데이트할 수 있습니다. 포터블은 새 ZIP을 풀어 실행하세요.
