# Chat Revo 1.1.0

새 채팅의 마지막 줄이 아래에 가려지는 문제를 수정하고, 글꼴 10종과 새 채팅 애니메이션을 추가했습니다.

## 채팅 표시 수정

- 치지직의 역방향 채팅 목록에 맞춰 마지막 스크롤 위치를 보정합니다.
- 글꼴·이모티콘 이미지 로딩, 글자 크기·줄 간격 변경, 오버레이 크기 조절 후에도 최신 채팅을 따라갑니다.
- 채팅 스타일 적용을 고정 150ms 지연에서 화면 갱신 프레임 단위로 변경했습니다.
- 위로 스크롤해서 이전 채팅을 읽을 때는 그 위치를 유지합니다. 아래로 돌아오거나 오버레이를 잠그면 최신 채팅을 다시 따라갑니다.

## 새 글꼴과 효과

기존 더잠실체에 다음 10종을 추가했습니다.

Wanted Sans · Pretendard · SUIT · IBM Plex Sans KR · 나눔고딕 · 고운돋움 · 고운바탕 · 배민 주아체 · 배민 도현체 · 한국기계연구원체

- 선택한 글꼴은 채팅과 상단 채널명에 적용됩니다. 별도 시스템 설치 없이 사용할 수 있습니다.
- 새 채팅 효과: 없음, 페이드, 떠오르기, 옆에서 들어오기, 팝
- 재생 시간 100~800ms, 움직임 크기 4~32px 조절
- 미리보기에서 샘플 채팅이 도착하므로 글꼴과 애니메이션을 바로 확인할 수 있습니다.
- 기존 설정은 유지합니다. 애니메이션 기본값은 없음입니다.

출처 – 한국기계연구원, https://www.kimm.re.kr/webfont
원본 폰트와 이용 조건은 앱의 `Assets/Fonts`에 동봉했습니다. 각 글꼴의 권리는 원저작자에게 있습니다.

## 업데이트

설치형은 설정 → 업데이트 → 업데이트 확인에서 다운로드하고 재시작하여 적용합니다.
포터블은 새 ZIP을 별도 폴더에 풀어 사용합니다. 설정과 로그인 데이터는 유지됩니다.

배포자 코드 서명은 아직 적용되지 않았습니다. 치지직 페이지 구조 변경 및 개별 게임 환경에 따른 호환성 제한은 유지됩니다.
