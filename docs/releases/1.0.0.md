# Chat Revo 1.0.0

창 모드와 테두리 없는 전체 창 모드 게임 위에 치지직 채팅을 표시하는 Windows용 개인 오버레이입니다.

## 주요 기능

- 채널 주소로 공식 채팅 연결, 앱 전용 네이버 로그인 세션
- 공식 채팅 웹뷰를 이용한 이모티콘·구독티콘·후원 및 구독 메시지 표시
- 채널명, 방송 상태 점, 시청자 수를 한 줄로 표시
- 더잠실체, 글자 크기·굵기·색상, 닉네임 색상 통일
- 외곽선 두께·색상, 그림자 강도·번짐·거리·색상
- 전체 배경과 메시지별 배경의 색상·불투명도, 줄 간격·메시지 간격
- 창 이동·크기 변경, 최상위 표시, 잠금 시 클릭 통과
- 미리보기, 설정 자동 저장, 트레이 메뉴
- 주간 후원 랭킹과 채팅 입력 영역 숨김

## 설치 및 실행

Windows 10 2004 이상 또는 Windows 11의 x64 환경에서 사용합니다. .NET 런타임은 포함되어 있으며 Microsoft Edge WebView2 런타임이 필요합니다.

- `ChatRevo-win-Setup.exe`: 설치형
- `ChatRevo-win-Portable.zip`: 압축을 풀고 `Chat Revo.exe` 실행
- 기존 0.x 버전은 앱 종료 후 새 버전을 실행합니다. 설정과 로그인 세션은 같은 사용자 데이터 폴더를 사용합니다.

`Ctrl+Alt+L` 잠금/해제 · `Ctrl+Alt+O` 표시/숨김 · `Ctrl+Alt+S` 설정 열기

창의 X는 트레이로 숨기며, 완전히 종료하려면 앱 종료 메뉴를 사용합니다.

## 알려진 제한

- 배포자 코드 서명은 아직 적용하지 않았습니다.
- 자동 업데이트는 공개 GitHub 릴리스와 설치형 앱을 사용합니다. 비공개 저장소 또는 릴리스 초안은 업데이트 원본으로 조회되지 않습니다. 공개 릴리스 간 업데이트는 아직 실증 검증 전입니다.
- 시청자 수는 치지직 웹사이트 인터페이스를 사용하며, 비공개 또는 확인 불가 상태는 `—`로 표시합니다.
- 치지직 페이지 구조 변경 시 스타일 어댑터의 수정이 필요할 수 있습니다.
- 독점 전체화면과 게임별 최상위 창 정책, 다중 모니터 DPI는 환경별 확인이 필요합니다.
- 모든 특수 메시지와 움직이는 구독티콘의 유형별 대조 검수는 완료되지 않았습니다.

현재는 공식 웹 로그인 방식이며 개발자 Client Secret을 요구하지 않습니다. Chat Revo는 네이버·치지직의 공식 앱이 아닙니다.
