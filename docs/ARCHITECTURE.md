# Chat Revo 아키텍처

## 구성

- `ChatRevo.Core`: URL/탐색 정책, 설정 모델, 정규화와 원자적 저장. UI 독립.
- `ChatRevo.Desktop`: WPF 화면, MVVM 상태/명령, WebView2 전용 프로필.
- `OverlayWindow`: 투명 WPF 창과 WebView2CompositionControl. 배경 alpha는 WPF 레이어에만 적용.
- `BrowserService`: 허용된 최상위 탐색, 권한/다운로드 제한, WebView2 환경 공유.
- `overlay.js`: 공식 채팅 CSS 어댑터와 시청자 수 어댑터. 원본 메시지 DOM 재생성 없음.
- `AppController`: 창 수명, 트레이, 단축키, 설정 저장 및 앱 조작.
- `UpdateService`: 배포 설정 검증, 안정 버전 조회/다운로드, 명시적 재시작.

## 인증 경계

공식 웹 로그인은 WebView2 프로필 쿠키로 동작한다. API OAuth 토큰과 호환되는 개념이 아니다. 현재 Client Secret을 사용하지 않는다. API 중계 서버가 필요해지면 서버에만 비밀키를 보관하며 공식 웹 로그인 쿠키를 서버로 전송하지 않는다.

외부 채팅 웹뷰에는 파일 시스템/쉘을 호출할 수 있는 HostObject를 노출하지 않는다. WebMessage는 방송 정보 문자열과 숫자만 받으며 발신 URL 및 채널 ID를 확인한다. 채팅 내용은 앱에서 HTML로 재삽입하지 않는다.

## 업데이트 경계

제작자 저장소 URL은 배포 파일에 고정한다. 사용자 입력 채널 주소를 업데이트 원본으로 사용하지 않는다. 저장소 없음/포터블/최신/네트워크 실패/다운로드 완료를 구분한다. 실패 시 현 버전을 계속 사용한다. 릴리스의 코드 서명은 배포 인프라 설정 후 추가 검증이 필요하다.

## 검수

단위 테스트: URL 형식/위장 도메인, 탐색 정책, 잘못된 설정 복구, 배율 및 범위 정규화.
Windows 스모크: 실제 WebView2 초기화, 로컬 미리보기, 스타일 변경, 클릭 통과 플래그, 포커스 보존, 선택 채널 로드 및 시청자 수, 스크린샷.
수동 검수: 사용자 로그인/추가 인증, 게임 위 표시, 다중 모니터 DPI, 각 후원/구독/움직이는 이모티콘/삭제 이벤트, 두 서명된 릴리스 간 업데이트.
