# 1.1.0 검증 기록

## 자동 검증

- Release 빌드: 오류 0, 경고 0
- Core 테스트: 26개 통과 (폰트/애니메이션 저장·기본값 호환·잘못된 값 정규화 포함)
- WebView2 브라우저 회귀: 정방향/역방향 목록, 연속 100개 메시지, 이미지 로딩, 글꼴/창 크기 변경, 이전 채팅 위치 유지, 잠금 복귀 및 효과 종료 후 가시성
- 11개 글꼴 및 별도 Bold 파일 8개가 실제 FontFace로 로딩되는지 확인
- CDP의 실제 휠 입력으로 과거 채팅 탐색 중 자동 스크롤 정지 및 맨 아래 복귀 확인
- 실제 Windows / WebView2 런타임에서 스모크 테스트 실행
- 공식 팝업 채팅 경로 `/live/{channelId}/chat` 확인
- 강홍타 채널 실시간 채팅 및 현재 시청자 수 수신 확인
- 더잠실체 정규 폰트 로딩 완료, 실제 메시지에 20px 적용 확인
- 미리보기에서 28px 변경 확인
- 외곽선/그림자/본문 및 닉네임 색상/줄 간격/메시지 배경 적용 및 해제 확인
- 실제 치지직 메시지에 외곽선과 그림자 적용 확인
- 헤더의 한 줄 정렬, 채팅 글자 크기 연동, 280px 창에서 긴 채널명 잘림 처리 확인
- 잠금 상태 WS_EX_TRANSPARENT / WS_EX_NOACTIVATE 확인
- WindowFromPoint로 실제 히트 테스트가 아래 창으로 통과함 확인
- 잠금 전환 시 전경 창이 바뀌지 않음 확인
- 주간 후원 랭킹 및 입력 영역 숨김 확인
- 원본 스타일 전환 시에도 주간 후원 랭킹 숨김 유지 확인
- 설정 파일 저장 확인
- 최종 화면 PNG로 다크 테마/텍스트 대비/잘림 여부 확인
- Velopack win-x64 설치형/포터블 패키지 생성
- 배포 대상은 `Revo-32/ChatRevo`, 앱 표시 버전은 어셈블리 버전에서 읽음
- 사용자 로그인 프로필과 분리된 데이터 폴더에서 배포 바이너리 스모크 실행

## 남은 사용자/배포 검증

- 사용자 네이버 계정 로그인 및 추가 인증
- 사용하는 게임에서 장시간 실행 및 재접속
- 다중 모니터 간 이동과 DPI/모니터 분리
- 실제 후원/구독/구독 선물/움직이는 구독티콘/삭제 메시지의 모든 유형 대조
- 개발자 애플리케이션 등록은 앱 실행에 선행 조건이 아님
- 설치형의 공개 릴리스 간 실제 교체/재시작 과정
- 배포자 코드 서명 설정

일반 이모티콘 이미지 표시를 관찰했지만 모든 이미지 유형을 검수 완료했다고 주장하지 않는다. 시청자 수 웹 API 경로는 비공식 인터페이스이며 오류 시 확인 불가 상태로 전환한다. 업데이트 해시 검증과 배포자 서명은 구분한다.

브라우저 회귀 실행 시 `CHATREVO_BROWSER_TEST_SCRIPT`를 `tests/ChatRevo.Browser/regression.js`의 절대 경로로 지정하고 `--smoke-test`로 실행한다. `CHATREVO_DATA_DIR`와 `CHATREVO_SMOKE_DIR`는 사용자 프로필과 다른 임시 폴더로 지정한다. 결과 JSON의 `error`가 없고 `browserRegression.ok` 및 개별 검증값이 true인지 확인한다.
