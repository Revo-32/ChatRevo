# Chat Revo

Windows 게임 위에 치지직 공식 채팅을 표시하는 개인용 오버레이입니다.

## 현재 버전

1.1.0입니다. C# / .NET 10 / WPF / WebView2로 구현했습니다.

설치 파일과 포터블 ZIP은 [GitHub Releases](https://github.com/Revo-32/ChatRevo/releases)에서 배포합니다. 변경 내용은 [1.1.0 릴리스 노트](docs/releases/1.1.0.md)에서 확인할 수 있습니다.

- 공식 채팅 웹 페이지를 사용하므로 이모티콘과 구독티콘을 직접 재구성하지 않습니다.
- 주간 후원 랭킹과 입력 영역은 숨깁니다. 실제 후원 메시지/구독 알림은 유지합니다.
- 차콜/오렌지 테마, 전용 SVG/ICO 로고, 커스텀 스크롤바/슬라이더/토글/색상 선택창
- 더잠실체·Wanted Sans·Pretendard 등 11개 글꼴, 12–48px, 본문 색상, 닉네임 색상 통일, 줄 간격/메시지 간격
- 새 채팅의 페이드·떠오르기·슬라이드·팝 효과 및 시간/움직임 크기 조절
- 역방향 목록의 자동 스크롤 보정, 이미지/글꼴/창 크기 변경 후 마지막 줄 따라가기, 과거 채팅 탐색 유지
- 외곽선 두께/색상, 그림자 강도/번짐/거리/색상, 전체 및 메시지별 배경 색상/불투명도
- 창 이동/크기 조절, 최상위 표시, 잠금 중 마우스 통과 및 비활성 창 처리
- Ctrl+Alt+L 잠금, Ctrl+Alt+O 표시/숨김, Ctrl+Alt+S 설정
- 전용 WebView2 프로필의 네이버 로그인/로그아웃
- 채널명 · 방송 상태 점 · 시청자 수를 한 줄로 표시. 채팅 크기에 맞춰 헤더 크기도 연동
- 시청자 수 30초 기본 갱신 및 실패 시 지수 백오프. 비공개/확인 불가 시 `—` 표시
- 로컬 설정 저장, 미리보기, 네트워크 재연결, 트레이 메뉴
- Velopack 업데이트 연동 및 GitHub Actions 빌드/패키징

## 실행과 빌드

Windows 10 2004 이상/Windows 11 x64, .NET 10 SDK, Microsoft Edge WebView2 Runtime이 필요합니다. 배포 패키지는 .NET 런타임을 포함합니다.

```powershell
dotnet build ChatRevo.slnx -c Release
dotnet test ChatRevo.slnx -c Release
dotnet run --project src/ChatRevo.Desktop -c Release
```

설정 창에서 채널 URL을 입력하고 **채팅 연결**을 누릅니다. 필요하면 **네이버 로그인**에서 공식 페이지로 로그인합니다. 오버레이의 위쪽 막대를 드래그해 위치를 정하고 오른쪽 아래 모서리로 크기를 바꾼 뒤 **위치 잠금 · 클릭 통과**를 누릅니다. 창 모드 또는 테두리 없는 전체 창 모드에서 사용합니다.

설정 창의 X는 트레이로 숨깁니다. 완전 종료 버튼이나 트레이의 종료 메뉴로 종료합니다.

## 데이터와 인증

기본 데이터 위치는 `%LOCALAPPDATA%\ChatRevo\UserData`입니다. `CHATREVO_DATA_DIR` 환경변수로 별도 경로를 지정할 수 있습니다. 실행 파일 밖에 보관하므로 업데이트 시 설정과 로그인 세션을 유지합니다.

네이버 계정의 비밀번호를 앱 설정에 저장하지 않습니다. 로그인 쿠키와 웹 캐시는 앱 전용 WebView2 프로필에 저장됩니다. 로그아웃은 이 프로필의 브라우징 데이터를 지우며, 다른 브라우저에는 영향을 주지 않습니다.

**현재 공식 웹 채팅을 여는 데 개발자 Client Secret은 사용하지 않습니다.** 개발자센터의 리디렉션 URL `http://localhost:42837/auth/callback`은 향후 Open API OAuth 개발에 사용할 예약 주소입니다. 현재 앱에는 OAuth 콜백 리스너/토큰 교환을 구현하지 않았으며 웹 로그인과 혼동하지 않아야 합니다.

시청자 수는 공식 웹사이트가 사용하는 `api.chzzk.naver.com/service/v3/channels/{id}/live-detail` 경로를 웹뷰 내부에서 조회합니다. 문서화된 Open API가 아니므로 변경될 수 있습니다. 어댑터는 `Assets/overlay.js`에 격리되어 있으며 실패 시 채팅을 중단하지 않습니다. `cvExposure=false`이면 숫자를 노출하지 않습니다. 필요하면 추후 서버 기반 공식 API 제공자로 교체합니다.

## 배포

`scripts/package.ps1`로 설치/업데이트 패키지를 생성합니다. `src/ChatRevo.Desktop/distribution.json`의 `githubRepository`를 실제 공개 저장소 URL로 설정하면 설치형 앱의 자동 업데이트가 활성화됩니다. 포터블 실행과 저장소 미설정 상태는 UI에서 구분합니다.

현재 비밀키나 GitHub 토큰을 앱에 넣지 않습니다. 업데이트 원본은 `Revo-32/ChatRevo`입니다. 저장소와 릴리스가 공개되어야 설치형 앱에서 인증 없이 조회할 수 있습니다. 새 버전은 백그라운드로 내려받고 재시작 버튼 또는 다음 시작 때 적용하며, 실행 중 강제로 재시작하지 않습니다. Velopack의 패키지 해시 검증을 사용합니다. **배포자 코드 서명과 실제 GitHub 릴리스 간 업데이트 검증은 아직 별도 배포 준비 사항입니다.** 해시 검증을 배포자 서명 검증과 동일하게 취급하지 않습니다.

GitHub Actions는 PR/푸시에서 빌드·테스트합니다. 버전 태그에서 패키지 아티팩트를 만들고 초안 릴리스를 생성합니다. 공개 릴리스 전 코드 서명, 설치/업데이트 회귀 검사, 폰트 고지 포함을 확인합니다.

## 호환성 한계

- 치지직의 웹 페이지 CSS 클래스 변경 시 사용자 스타일 수정이 필요할 수 있습니다. **원본 스타일로 보기**를 사용해 원래 화면으로 복귀할 수 있습니다.
- 게임별 최상위 창 정책과 독점 전체화면은 별도 검증 대상입니다.
- 로그인/추가 인증은 사용자 직접 조작이 필요합니다. 내장 브라우저에 대한 네이버 측 정책 변경은 앱에서 우회하지 않습니다.
- 모든 메시지 유형/움직이는 구독티콘/블라인드 처리는 실제 발생한 사례로 검수해야 합니다. 표시 방식만으로 검증 완료를 주장하지 않습니다.
- 브라우저 프로세스 오류는 재연결 또는 앱 재시작이 필요할 수 있습니다.

## 라이선스

Chat Revo 자체 소스의 공개 라이선스는 제작자 결정 전입니다. 포함 폰트의 출처와 이용 조건은 [폰트 안내](docs/FONTS.md)와 앱의 `Assets/Fonts`에 포함했습니다. 출처 – 한국기계연구원, kimm.re.kr. WebView2 및 Velopack은 각 배포 라이선스를 따릅니다. 치지직과 네이버는 해당 권리자의 서비스입니다.
